             jour, mois, source, zone — Nodata: -9999

2. marseille-engine/ — BACKEND API
================================================================================

Stack: Python 3.13, FastAPI, uv — Port: 8000 — Docs: http://localhost:8000/docs
Package manager: uv — IMPORTANTE: sempre UV_PYTHON=/usr/bin/python3

--- Avvio ---
make run             → solo API
make start           → API + marseille-app (5173)
make start-dashboard → API + marseille-dashboard (5174)
make start-mobile    → API + fresh-route Expo (8081)

--- Struttura routers ---
api/routers/
├── uhi.py       → /uhi/quartiers, /uhi/quartier/{nome}, /uhi/point
├── history.py   → /history/zones, /history/{zona}
├── route.py     → /route/ (A★ green routing)
├── risk.py      → /risk/?month=
├── raster.py    → /uhi/raster.png, /uhi/raster/raw, /uhi/raster/bounds,
│                   /uhi/raster/all-zones-history
└── timeline.py  → /timeline/snapshot?year=, /timeline/range

--- Endpoint chiave ---
GET /uhi/quartiers              → GeoJSON 111 quartieri + uhi_score/rank
GET /uhi/point?lat=&lon=        → UHI score per coordinata
GET /history/{zona}?from=&to=  → LST + trend °C/decade (MODIS)
GET /risk/?month=               → GeoJSON quartieri con risk_level
GET /route/?from_lat=...        → percorso A★ pesato UHI
GET /uhi/raster.png?scale=0.3  → PNG colorizzato (statico)
GET /uhi/raster/raw?scale=0.3  → float32 binario + headers X-Raster-* (WebGL)
GET /uhi/raster/all-zones-history → {zone:{year:{lst,anomaly,anomaly_norm}}}
GET /timeline/snapshot?year=   → {zone: {lst, anomaly, anomaly_norm}} per 9 zone

--- Routing algorithm ---
A★ (nx.astar_path) con euristica geografica euclidea in CRS proiettato
green_weight: lunghezza base + sconto 35% pedonale + sconto 30% fresco + penalità 40% caldo

--- Boot sequence ---
1. Carica marseille_uhi.tif in RAM (np.ndarray, NaN=nodata)
2. Carica quartiers.geojson + zonal_stats → 111 quartieri con uhi_mean/score/rank
3. Carica MODIS CSV
4. Scarica grafo OSM Marsiglia 3.3km (cached su disco) + applica green_weight

--- WebGL raster layer ---
Architettura: download float32 raw UNA VOLTA al mount (~1.7MB),
poi setYear(year) → aggiorna u_shift uniform → GPU re-render senza HTTP.
Shader GLSL: LUMINANCE texture float → heat colormap (verde→rosso) + anomaly shift.
Anomaly shift: media zone_anomaly_norm × 0.15 → ±15% shift sul colore.
OES_texture_float extension richiesta (supportata da tutti i browser moderni).

--- Features dashboard ---
- KPI: avg UHI, hot/cool districts count, hottest/coolest zone
- Mappa Leaflet dark con WebGL raster overlay (pixel-level)
- Toggle: 🛰 Pixel / ⬡ Districts / ⊕ Both
- Timeline slider 2000→2024 fisso sotto la mappa (sempre visibile)
- Ranking 111 quartieri con click → highlight + flyTo mappa
- Quartier detail: score gauge, vs avg, percentile, monthly risk, distribution histogram
- Trend chart 2000→2024 con linea regressione + highlight 2003
- Seasonal profile con barre colorate per temperatura
