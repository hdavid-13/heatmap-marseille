--- Struttura routers ---
api/routers/
├── uhi.py       → /uhi/quartiers, /uhi/quartier/{nome}, /uhi/point
├── history.py   → /history/zones, /history/{zona}
├── route.py     → /route/ (A★ green routing)
├── risk.py      → /risk/?month=
├── raster.py    → /uhi/raster.png, /uhi/raster/raw, /uhi/raster/bounds,
│                   /uhi/raster/all-zones-history
└── timeline.py  → /timeline/snapshot?year=, /timeline/range

--- Endpoint chiave ---
GET /uhi/quartiers              → GeoJSON 111 quartieri + uhi_score/rank
GET /uhi/point?lat=&lon=        → UHI score per coordinata
GET /history/{zona}?from=&to=  → LST + trend °C/decade (MODIS)
GET /risk/?month=               → GeoJSON quartieri con risk_level
GET /route/?from_lat=...        → percorso A★ pesato UHI
GET /uhi/raster.png?scale=0.3  → PNG colorizzato (statico)
GET /uhi/raster/raw?scale=0.3  → float32 binario + headers X-Raster-* (WebGL)
GET /uhi/raster/all-zones-history → {zone:{year:{lst,anomaly,anomaly_norm}}}
GET /timeline/snapshot?year=   → {zone: {lst, anomaly, anomaly_norm}} per 9 zone

--- Routing algorithm ---
A★ (nx.astar_path) con euristica geografica euclidea in CRS proiettato
green_weight: lunghezza base + sconto 35% pedonale + sconto 30% fresco + penalità 40% caldo

--- Boot sequence ---
1. Carica marseille_uhi.tif in RAM (np.ndarray, NaN=nodata)
2. Carica quartiers.geojson + zonal_stats → 111 quartieri con uhi_mean/score/rank
3. Carica MODIS CSV
4. Scarica grafo OSM Marsiglia 3.3km (cached su disco) + applica green_weight

--- WebGL raster layer ---
Fix: float32 incompatibile con WebGL1 su alcuni device → encoding CPU-side in Uint8.
Texture LUMINANCE UNSIGNED_BYTE: v normalizzato in [1,255], 0=nodata.
Shader: if (norm < 0.004) discard; altrimenti heat colormap verde→rosso.
Anno selezionato → u_shift uniform → GPU re-render senza HTTP.

--- Features dashboard ---
- KPI: avg UHI, hot/cool districts count, hottest/coolest zone
- Mappa Leaflet dark con WebGL raster overlay (pixel-level)
- Toggle: Pixel / Districts / Both
- Timeline slider 2000→2024 fisso sotto la mappa
- Ranking 111 quartieri con click → highlight + flyTo mappa
- Quartier detail: score gauge, vs avg, percentile, monthly risk, distribution histogram
- Trend chart 2000→2024 con linea regressione + highlight 2003
- Seasonal profile con barre colorate per temperatura

--- Home screen (index.tsx) — architettura ---
- PanResponder sul View root cattura swipe (dx < -60 → next, dx > 60 → prev)
- panOffsetRef (useRef<number>) aggiornato direttamente nel PanResponder
  → NIENTE setState/Animated durante lo swipe → zero re-render React
- Canvas Three.js avvolto in View pointerEvents="none"
  → le gesture vanno al PanResponder, non al canvas
- key={isFocused ? "focused" : "blurred"} sul Canvas
  → forza remount WebGL context quando si torna sulla schermata
- navigatingRef (useRef<boolean>) in handleOrbTap
  → impedisce chiamate concorrenti a calculateFromDemo

--- Tecnica punti (Three.js Points) ---
- Ogni componente: useMemo (geometry) + BufferGeometry + BufferAttribute
- PointsMaterial: map=circleTex, alphaTest=0.1, vertexColors, sizeAttenuation
- circleTex: canvas gradient radiale 64×64 → CanvasTexture (texture circolare)
- Colors animati (Water, Windows): needsUpdate=true in useFrame
- TUTTO a punti — nessun Mesh/MeshStandardMaterial

--- API (src/api/engine.ts) ---
- BASE: http://localhost:8000
- fetchWithTimeout(url, signal?): AbortController interno 5000ms + signal esterno
- fetchRoute/fetchRisk/fetchUHIPoint: tutti accettano optional AbortSignal
- heatmap.tsx useEffect: AbortController + cleanup → niente richieste orphan

--- Guard anti-loop ---
navigatingRef in index.tsx e routes.tsx: se navigatingRef.current=true → return immediato
Previene chiamate concorrenti a calculateFromDemo (causa principale del GET loop)
